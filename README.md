# IMEX Mosaic Studio · downloads

Installers and update files for **IMEX Mosaic Studio**, the mosaic design app of IMEX International Co., Ltd.
This page holds no source code.

- Download the newest version from **Releases** (Mac `.dmg`, Windows `.msi`).
- The app needs an **IMEX licence** made for your computer; without one it only shows the activation screen.
- Installed apps update themselves from here; every update is signed by IMEX and checked before it is installed.
